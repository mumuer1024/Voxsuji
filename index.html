Voxsuji

把在线视频变成结构化、可缓存的文字稿

Voxsuji 是一个小型 CLI：给定一个视频 URL，优先使用现成字幕；没有字幕时自动提取音频并调用你配置的云端 ASR。输出 JSON、Markdown 和 SRT，既适合直接阅读，也适合交给 AI Agent 继续处理。

voxsuji — zsh

HOW IT WORKS

一个 URL，三段输出

Voxsuji 处理视频的核心流程：字幕优先，ASR 兜底，结果统一格式化。

🔗

视频 URL

`voxsuji transcript <URL>` — 只需一条命令。

📼

yt-dlp 获取视频信息与字幕

提取能力来自 yt-dlp；YouTube 是主要验证来源，其他支持的网站按 best-effort 工作。

💬

发现可用字幕？

✅ 有字幕 → 直接解析

不产生 ASR 调用，零额外成本，通常也是最快的路径。

🎙️ 无字幕 → ASR fallback

提取音频 → 临时上传 S3-compatible 对象存储 → 调用云端 ASR（阿里云百炼 / 火山引擎 / 腾讯云）。临时对象在转录完成后自动清理。

⚙️

统一格式化

字幕或 ASR 结果归一化为同一份结构化 transcript，是后续所有输出的唯一数据源。

📄

输出 JSON / Markdown / SRT

同一份 transcript 生成三种格式：JSON 权威、Markdown 易读、SRT 可当字幕文件。

QUICK START

快速开始

Python 3.10+ 和 ffmpeg 即可。yt-dlp 会自动装进项目自己的虚拟环境，不碰系统 Python。

bash
$ git clone https://github.com/mumuer1024/Voxsuji.git # 克隆仓库 $ cd voxsuji && sudo apt-get install -y ffmpeg $ cp .env.example .env && chmod 600 .env && cp config.example.ini config.ini $ ./bin/voxsuji doctor # 检查依赖与配置 ✔ ffmpeg found · provider: aliyun · storage reachable $ voxsuji transcript <URL> # 字幕优先，无字幕时自动 ASR ✓ cache/youtube/<video_id>/transcript.md ℹ stdout 只返回 JSON 摘要，不会刷屏整个文字稿

📌 常用命令

  • voxsuji transcript <URL>
  • voxsuji transcript <URL> --provider aliyun
  • voxsuji transcript <URL> --language zh
  • voxsuji transcript <URL> --force-asr --refresh
  • voxsuji doctor

--force-asr 会跳过原本免费的字幕路径并产生 ASR 费用，非必要不要用。

🤖 直接交给 Agent

在 Claude Code、Codex、Cursor 等工具里运行 voxsuji，读取生成的 transcript.md 再总结即可——Voxsuji 本身不调用任何 LLM。

OUTPUTS

输出什么

默认缓存结构，以及成功时 stdout 的 JSON 契约。

📁cache/· 缓存目录结构
cache/<platform>/<video_id>/
├── transcript.json   # 标准化结构 · 权威数据源
├── transcript.md     # 适合直接阅读 / 交给 AI
├── transcript.srt    # 字幕格式
├── meta.json         # 标题 · 上传者 · 时长
└── raw/
    └── asr_<provider>.json  # ASR 原始响应（调试用）

AI AGENT

和 AI Agent 一起使用

Voxsuji 有意不把完整文字稿输出到 stdout——几小时的视频不会突然塞满 Agent 的上下文。

用户给出视频 URL
Agent 运行 voxsuji transcript <URL>
读取 stdout 的 JSON summary
找到 files.markdown
增量读取 transcript.md（长文字稿分段读）
总结 / 整理 / 分析，按你的需求输出
💬可以直接对 Agent 说的话
“用 voxsuji 获取这个视频的完整文字稿：优先使用平台现有字幕，必要时使用已配置的 ASR。
完成后读取生成的 Markdown 文字稿，并为我总结主要内容。不要修改 voxsuji 项目本身。”
prompts/ 目录另提供 full-summary / structured-notes / lecture-notes / transcript-cleanup 模板

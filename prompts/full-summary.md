# Full summary

You are given the transcript of an online video. Produce a clear, well-organized summary of its content.

<TRANSCRIPT>

## Instructions

1. Read the entire transcript before writing.
2. Write an executive summary (2–4 sentences) that captures the main message.
3. List the key points as concise bullet points, in the order they appear.
4. Include any concrete numbers, names, dates, or claims worth remembering.
5. Note anything that is clearly uncertain, speculative, or stated as opinion.

## Output format

```markdown
## Executive summary
<2–4 sentences>

## Key points
- ...

## Notable details
- ...

## Caveats / open questions
- ...
```

Rules:
- Stay faithful to the source; do not invent facts.
- If the transcript has timestamps, you may reference approximate positions.
- Write in the language of the transcript unless the user asks otherwise.
